# Smartify WEB - Local Business Templates Factory

Este projeto é uma infraestrutura de desenvolvimento de alta performance baseada no Porto HTML5, otimizada para a criação ágil de sites para negócios locais brasileiros.

## 🚀 Status Atual do Projeto
- **Core**: Vite 5+ (Modern Frontend Tooling)
- **Base**: Porto Full Library (45+ Demos)
- **Localização**: 100% pt-br (lang tags)
- **Deploy**: GitHub Actions configurado para GitHub Pages
- **Ativos**: ~2.000 arquivos de imagens e assets otimizados

## 🏗️ Arquitetura de Diretórios
- `/src`: Ambiente de desenvolvimento (Edite seus HTMLs aqui).
- `/public`: Ativos estáticos legados (JS, CSS, Imagens, Fontes).
- `/dist`: Versão final de produção (Gerada automaticamente pelo build).
- `/.github`: Automação de deploy para o servidor.

## 🛠️ Comandos Principais
- `npm run dev`: Inicia o servidor local com Hot Reload.
- `npm run build`: Gera a versão otimizada para o cliente final.
- `git push`: Sincroniza e publica as alterações automaticamente.
